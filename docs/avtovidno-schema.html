Аккаунт — одна станция. Без автопродления: следующий период оплачиваете сами.

Боль, которую продаём — не «учёт»

Звонки «когда готово?»

Клиент не видит статус. Мастер отвечает из ямы. Ссылка закрывает этот разговор: статус, дата, список работ — в телефоне.

«Я это не заказывал»

Смета уходит на согласование. Клиент жмёт «ок» или «переделать». После выдачи ещё раз подтверждает, что всё так. История не переписывается.

Тетрадка и память

Повторный визит — поиск по госномеру. Видно, что уже делали, какой был пробег, какие работы. Не «кажется, масло меняли весной».

Две двери в одну систему

СТО входит с логином. Клиент — по ссылке, без регистрации. Оба смотрят одни и те же данные.

Кабинет СТО

Ремонты, новый заказ, гараж, профиль станции, мастера, подписка.

Вход по email. Если пробный период или оплата кончились — кабинет закрывается, пока не оплатят. Публичные ссылки клиентов при этом живут.

Публичная карточка авто

Статус, работы, сумма, контакты СТО, история. Можно согласовать смету и подтвердить выдачу.

Токен привязан к автомобилю, не к одному заказу. Второй ремонт — та же ссылка.

«Мы не ставим программу на компьютер СТО. Браузер, телефон, ссылка клиенту. Данные станции изолированы: чужая СТО чужие машины не видит.»

Данные крутятся вокруг автомобиля

Станция — контейнер. У клиента может быть несколько машин. У каждой машины — вечная ссылка и лента ремонтов.

Изоляция

Каждая станция видит только своих клиентов и авто. Поиск по госномеру не показывает чужой сервис.

Пробег

После «Выдан» система запоминает пробег. Следующий заказ нельзя завести с меньшим — защита от перезаписи истории.

Заказ как конвейер, не как чат

СТО двигает статус. Клиент вмешивается в двух местах: согласование работ и подтверждение после выдачи. «Ждём запчасти» можно пропустить.

Новый → На согласовании → В работе → Ждём запчасти → Готово → Выдан

Согласование сметы клиент

СТО жмёт «на согласование». Клиент по ссылке видит список работ и отвечает: принять или вернуть на правку.

Пока клиент не ответил, заказ нельзя закрыть и выдать.

Подтверждение выдачи клиент

Статус «Выдан» — СТО больше не правит заказ. Клиент подтверждает или пишет, что есть ошибка. После «ок» карточка навсегда только для чтения.

Если спор — мастер правит и снова отправляет на подтверждение.

# Создание авто для существующего клиента (ТЗ для Laravel)

Фронт (React SPA «Автовидно») на странице `/repairs/new` в панели «Автомобили клиента» (кнопка
«Добавить авто») и в карточке ремонта добавляет автомобиль существующему клиенту.

**Проблема:** сейчас фронт пробует `POST /clients/{id}/vehicles`, при 404/405/HTML-ответе — фоллбэк
на `POST /vehicles`. Ни один из эндпоинтов не создаёт запись → «ничего не добавляется».

## Требуемый эндпоинт

### `POST /clients/{clientId}/vehicles` (auth, staff)

Создаёт автомобиль и привязывает к клиенту **той же станции**.

Body:

```json
{
  "car_model": "Toyota Camry",
  "license_plate": "А123ВС777",
  "vin": "JTDBE32K600000000",
  "chassis_number": null,
  "mileage": 85000
}
```

Поля из запроса фронта (`buildCreateVehicleRequest`):

| Поле                                            | Тип            | Обязательное | Примечание                                                                                    |
| ----------------------------------------------- | -------------- | ------------ | --------------------------------------------------------------------------------------------- |
| `client_id`                                     | int/string     | да           | может дублировать clientId из URL                                                             |
| `car_model`                                     | string         | да           |                                                                                               |
| `license_plate`                                 | string         | да           | госномер РФ, нормализация                                                                     |
| `vin`                                           | string \| null | см. ниже     | 17 симв., без I/O/Q                                                                           |
| `chassis_number`                                | string \| null | см. ниже     | 5–25 симв., латиница/цифры                                                                    |
| `mileage`                                       | int            | да           | ≥ 0                                                                                           |
| `client_name` / `client_phone` / `client_email` | string         | нет          | фронт шлёт для удобства (имя/телефон/почта клиента) — можно игнорировать или обновить клиента |

**Валидация VIN/шасси:** допустимо ровно одно из двух (VIN **или** номер шасси). Если оба
null/пустые → 422.

**Ограничение:** клиент должен принадлежать `service_station_id` текущего пользователя, иначе
403/404.

### Ответ: 201

```json
{
  "data": {
    "id": 123,
    "car_model": "Toyota Camry",
    "license_plate": "А123ВС777",
    "vin": "JTDBE32K600000000",
    "chassis_number": null,
    "mileage": 85000
  }
}
```

`id` — обязателен, фронт без него показывает ошибку «Сервер не вернул id автомобиля».

### Ошибки

| Код | Случай                                                                                                                  |
| --- | ----------------------------------------------------------------------------------------------------------------------- |
| 401 | не авторизован                                                                                                          |
| 403 | клиент с другой станции                                                                                                 |
| 404 | клиент не найден                                                                                                        |
| 422 | пустая `car_model`; неверный `license_plate`; нет ни VIN ни шасси; неверный VIN/шасси; `mileage` не число/отрицательный |

422 — формат стандартный: `{ "message": "...", "errors": { "field": ["msg"] } }` (фронт мапит на
поля формы).

## Примечания

- Фоллбэк `POST /vehicles` — legacy: лучше реализовать именно `/clients/{clientId}/vehicles`, тогда
  фоллбэк не понадобится.
- После создания авто клиент **не должен** терять свои данные.
- Фронт после успеха сам обновляет кэш (`optimistic update` + инвалидация `Client`,
  `Vehicle SEARCH`).
- Дубли госномера: если такой номер уже есть у клиента станции — допустимо 422 (или вернуть
  существующее авто — решить на бэкенде; фронт умеет оба варианта, но возвращать надо с `id`).
